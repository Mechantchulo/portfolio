## Overview

The portfolio has two intentionally distinct visual systems connected by one persistent switch. Content stays in the same order across modes.

## Colors

Cyber uses near-black, neon green, and cyan. Builder uses an off-white page, black text, thin borders, and one pale yellow-green feature panel.

## Typography

Cyber headings and terminal content use IBM Plex Mono. Builder headings use Space Grotesk. Body copy uses DM Sans in both modes.

## Layout

The desktop hero pairs copy with a terminal or bento grid. At tablet and mobile widths, the feature follows the copy. Projects use two columns on wide screens and one column on mobile.

## Elevation & Depth

Cyber panels use subtle translucency and soft glow on interaction. Builder panels are flat, opaque, and separated by thin borders.

## Shapes

Cyber panels have modest rounding; builder cards and buttons have square edges. The mode switch is pill-shaped in both.

## Components

The top navigation contains the mode switch. The hero pairs the work link with a CV download. Project cards use a common data source. The terminal accepts typed commands, color codes skill groups, and animates a simulated scan. `reboot` and `startx` use a full viewport transition before Builder Mode appears. The credentials rail uses horizontal scroll snapping and arrow controls. Certificate images display uncropped so their text remains intact.
